WellRise - Hack The North 2024 🤖

n Arduino Uno goose shaped (Go UWaterloo Warriors!) sensor device with a Flask web application to collect and monitor real-time sensor data via a dynamic website using JSON.

This project integrates an Arduino Uno with a Flask web application to monitor real-time sensor data. The Arduino collects data from various sensors, which is sent to the backend in JSON format. The Flask app processes and stores the data, then displays it on a dynamic website where users can view trends and monitor sensor readings in real-time. The system combines embedded systems with a full-stack web interface for efficient data tracking and visualization.

Fun fact - The physical Goose Base was designed and printed from scratch!

Pantry Pal

Full-stack web app that provides recipe suggestions using OpenAI.

A dynamic online service focused on improving pantry management and decreasing unnecessary food spoilage. Tracks food items and offers recipe suggestions for those about to expire, helps users efficiently use their ingredients and avoid waste.

Movie Filter

Full-stack website that gives movie suggestions, using Flask with backend databases and RapidAPI.

Flask-based web application that integrates with the MoviesDatabase API to fetch and display real-time movie and series data. It supports advanced search filtering, allowing users to query by exact title or keyword, and to specify content type.
